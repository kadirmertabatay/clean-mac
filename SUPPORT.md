# Getting help

- **Questions and ideas:** start a thread in [Discussions](https://github.com/kadirmertabatay/clean-mac/discussions).
- **Something isn't working:** check the [FAQ and Troubleshooting](docs/faq.md) first, then open a [bug report](https://github.com/kadirmertabatay/clean-mac/issues/new/choose).
- **Security issues:** please report them privately as described in [SECURITY.md](SECURITY.md).

CleanMac is maintained in spare time, so replies may take a few days. Thanks for your patience!
